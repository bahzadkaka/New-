# Oral Care Chatbot

Plain HTML, CSS, and JavaScript chatbot with a browser-based admin panel.

## Pages
- `index.html` — customer chatbot
- `admin.html` — admin panel

## Admin login
Default demo password: `admin123`

## Important
This version stores data in the browser using `localStorage`. The demo password is front-end only and is not secure enough for a production business system. A future production version should use a backend and proper authentication.
